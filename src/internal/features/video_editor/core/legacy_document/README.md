# 旧视频文档与现有宿主入口

本包从原 `internal/video` 迁入，保留已经存在的视频文档 v1 读取/编辑、导出计划、标量宿主会话与时间线几何。正式 v2 核心只在旧草稿迁移和共用画面裁剪等既有边界调用本包；Windows 旧编辑器仍通过根 ABI 使用这些入口。

这不是用户插件 v1 兼容层，也不接收插件清单或执行插件。新剪辑行为应实现于父包 `video_editor/core`，共享 UI 在 `video_editor/ui`。待 Windows 媒体/编辑器完成 v2 接入后，删除不再使用的旧编辑入口；保留素材与已有草稿读取，不为了去掉旧目录丢弃文档。时间线几何的现有调用保持不变，未来出现明确共享包边界时再提取，见 [时间线边界](TIMELINE.md)。
