# 可复用时间线边界

`timeline_geometry.mbt` 只负责像素/毫秒映射、刻度间隔和单个裁剪端点约束，无文档、会话、录屏或媒体依赖；只使用基础数值运算及 `double` 包。`bindings/c/video_timeline.h` 的四个 `video_timeline_*` 标量接口提供原生调用边界。以后拆库时可一起迁出几何文件、对应测试及头文件的几何声明。

这些函数目前仅构成共享几何基础，尚未形成共享界面。完整组件的布局、绘制描述、命中、拖拽、键盘和辅助功能语义应放在同一套 MoonBit UI 中；不要让 macOS、Windows 和 Linux 分别实现时间线视图后仅调用这些数值函数。组件与平台边界见[共享编辑组件约定](../../../../../../docs/shared-editor-ui.zh-CN.md)。

轨道支持任意有限起点与可表示的正宽度，越界拖动会夹到轨道两端。非法输入返回 NaN，宿主保留原来的选择。裁剪范围以整数毫秒保存；最短间隔由调用者提供，向上取整，最多为原片时长，因此不足一个常用帧长的短片仍可选择完整范围。拖动固定另一端点，不偷偷移动整个范围。

共享视图负责命中区域、手势、绘制描述、辅助功能语义与缩略图展示。应用接入层提供时长、裁剪范围和删除区间；媒体适配提供预先解码的缩略图，系统后端转发统一输入事件并呈现视图。拖动过程只更新临时预览；结束后向现有视频 reducer 提交一次 `trim`，取消则恢复原值。核心 reducer 仍执行最终验证，例如删除区间不能覆盖全部保留内容。

`video_source_time(session, outputMs)` 是文档适配接口，不是独立组件的依赖。它读取现有视频会话的编辑计划，把成片播放位置映射到原片；剪接点归下一段，成片终点归最后保留的毫秒，与既有 `video_seek` 的终点约定一致。无效会话或时间返回 -1。播放时钟、AVPlayer、解码及持久化留在宿主；不新增时间线状态、草稿格式或历史栈。
