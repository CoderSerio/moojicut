# Mooncap 产品需求文档

版本：0.1，评审稿，2026 年 11 月 13 日。

首轮验收平台：macOS arm64；产品与代码设计兼顾后续 Windows 和 Linux。

Mooncap 是供人和 Agent 共用的本地截图与录屏工具。平时驻留菜单栏或系统托盘，使用不同快捷键唤起截图和录屏。截图框选后原地标注，录屏结束后预览编辑，两条流程都以“确认后复制到剪贴板”为默认完成方式。

本 PRD 定义目标行为和验收条件，不代表现有概念原型已经实现。实现状态继续由 README 与验收记录说明。本文与旧交互草案冲突时，以本文为准。

产品形态修正：目标为 MoonBit native 驱动的原生菜单栏工具，取消独立首页／工作台，首选项采用紧凑的原生系统控件，最近记录优先放在菜单中。后续实现以 [原生路线决策](native-direction.md) 为准，现有 Electron 窗口仅作为旧实现参考。

## 1 已确认的产品约束

以下是本轮已经确认的要求。后文的工具细节、默认值及未单独确认的优先级，是本版用于评审的具体设计。

| 项目 | 已确认要求 |
| --- | --- |
| 截图流程 | 框选完成后支持标注，用户确认后默认复制图片到剪贴板 |
| 录屏流程 | 录制完成后支持编辑，用户确认后默认复制视频文件到剪贴板 |
| 功能入口 | 截图和录屏使用不同快捷键，菜单中也有独立入口 |
| 视频首版范围 | 首尾裁剪、删除片段、画面裁切和静音；视频文字、箭头和遮挡放到下一阶段 |
| 产品经验 | 继承 Snaplane 的原地标注、轻量工具栏、人和 Agent 共用编辑能力等经验 |
| 技术方向 | 更多业务、交互和界面使用 MoonBit 实现，保留必要的平台适配 |
| UI 选型 | 先选择能用、好维护的库，不把 TSX 或特定声明式语法当作要求 |
| 平台方向 | macOS arm64 先验收，同时考虑跨平台，不把平台差异写进共用业务模型 |

## 2 用户与使用场景

主要用户是日常需要截图解释问题、录制操作过程、编写文档的个人用户，以及协助这些工作的 Agent。

| 场景 | 用户任务 | 完成结果 |
| --- | --- | --- |
| 解释界面问题 | 截一块区域，画箭头、框选重点、补文字 | 确认后可直接在聊天或文档中粘贴图片 |
| 分享操作过程 | 录制一段操作，删除等待和失误片段，裁掉无关画面 | 确认后可粘贴 MP4 文件 |
| 对照信息 | 把截图置顶，回到原应用继续操作 | 图片保持可见，可移动、缩放和关闭 |
| 人机接力 | 人先截图，Agent 补标注，人调整后确认 | 各方操作作用于同一份编辑状态 |
| 恢复编辑 | 关闭视频编辑窗，稍后从最近记录重新打开 | 原素材和剪辑草稿仍然存在 |

用户不需要新建项目、命名工程或先选择保存目录，才能完成一次截图或录屏。需要文件保存时再使用次要入口。

## 3 首版范围与后续范围

P0 表示首个可日常使用版本必须满足；P1 表示下一阶段扩展；P2 表示暂不安排。P0 可以分里程碑实现，但缺少任一核心闭环时不得宣称首版完整交付。

| 领域 | P0 首版 | P1 下一阶段 | P2 暂不安排 |
| --- | --- | --- | --- |
| 入口 | 托盘、两种唤起快捷键、停止快捷键、冲突提示与修改 | 开机启动 | 常驻工作台首页 |
| 截图来源 | 单屏区域、当前屏全屏、菜单选择窗口、导入常见图片 | 窗口自动吸附、滚动截图 | 跨显示器拼接截图 |
| 截图标注 | 形状、直线与箭头、画笔、荧光笔、矩形马赛克与实色遮挡、文字、整对象橡皮擦 | 折线、编号、模糊、局部擦除笔迹、多选与图层面板 | 图像修复、复杂滤镜 |
| 对象编辑 | 单对象选择、移动、适用对象缩放、样式修改、删除、撤销重做 | 旋转、多对象对齐、自由笔迹节点编辑 | 矢量绘图软件式路径编辑 |
| 截图输出 | 确认复制、保存 PNG、置顶贴图、最近记录重开 | 面向人的可编辑包导入导出入口 | 云端图库 |
| 录制 | 单屏区域或全屏、麦克风、系统声音、3 秒倒计时、明确停止、异常保留 | 独立窗口录制、暂停继续、60 fps、摄像头叠加 | 多机同步采集 |
| 视频编辑 | 首尾裁剪、重复删除多个片段、全片固定画面裁切、全片静音、撤销重做 | 带时间范围的文字、箭头和遮挡、导入已有视频 | 多轨、转场、自动字幕、运动跟踪 |
| 视频输出 | MP4、确认复制文件、另存为、显示位置、失败重试 | 更多编码预设和输出格式 | 自动上传与分享链接 |
| Agent | 截图、读状态、标注、裁剪、撤销重做、预览、展示、导出与复制 | 录屏控制、视频剪辑命令、录像自动分析 | 产品内置对话模型 |
| 平台 | macOS arm64 验收，共用逻辑与平台适配分开 | Windows、Linux 按平台能力逐项验收 | 未验证平台的兼容承诺 |

首版的“马赛克”必须有实际像素化效果；实色矩形不能代替马赛克验收。“视频标注”不属于首版要求。

## 4 产品界面与公共规则

### 4.1 按需出现的界面

| 界面 | 出现条件 | 主要内容 | 退出后的状态 |
| --- | --- | --- | --- |
| 菜单栏或托盘 | 应用运行时 | 截图、录屏、最近记录、设置、退出；录制或编码时显示任务状态 | 应用继续驻留 |
| 截图覆盖层 | 唤起区域或全屏截图 | 冻结画面、选区、一级工具栏、当前工具属性栏 | 确认成功后回到原应用 |
| 窗口来源选择器 | 从菜单选择窗口截图 | 窗口名称与预览 | 选中后进入临时图片编辑窗 |
| 图片编辑窗 | 打开历史、导入图片或窗口截图 | 图片与相同的标注工具 | 关闭后回到待命 |
| 录制准备层 | 唤起录屏 | 选区、声音与指针设置、开始按钮 | 开始录制或取消 |
| 录制控制条 | 正在录制且能够放在区域外或被可靠排除 | 时长、录制状态、停止文字按钮 | 停止后进入收尾 |
| 视频编辑窗 | 录制收尾成功，或主动打开视频草稿 | 播放器、时间线、剪辑工具、确认按钮 | 确认成功后收起；普通关闭保留草稿 |
| 最近记录与设置 | 用户从菜单主动打开 | 本机素材、草稿、快捷键、存储管理 | 关闭后应用继续驻留 |

新鲜的区域或全屏截图必须在同一冻结画面中完成框选和标注。窗口截图、历史和导入图片使用独立编辑窗，不把它们伪装为原地桌面截图。

### 4.2 操作反馈

- 工具选中态、按钮按下态、禁用态和任务处理中状态明确区分。
- 图标具有完整提示、可访问名称和键盘焦点。截图确认可以用图标，提示为“确认并复制图片”；视频确认保留“确认并复制”文字。
- 颜色、线宽等属性只在相关工具激活或对象选中时出现；当前设置可见。
- 显示错误的同时保留可重试内容。复制失败不能收起编辑层，取消保存不能丢失标注。
- 任何功能不能显示可操作后再静默忽略。平台不支持的能力应禁用并说明原因。
- 界面使用中文。文件格式、像素尺寸、时长与进度使用一致单位。

### 4.3 并行任务规则

首版同一时刻只运行一个采集会话，即一次截图或一次录制。已有截图草稿时再次按截图快捷键，定位当前草稿，不新建第二份。切换到录屏需先完成或取消该截图。

录制中再次按录屏快捷键只定位当前控制；按截图快捷键提示“请先结束当前录制”。结束录制后，编辑草稿可以保存并关闭，再开始另一项采集。首版一次只执行一个视频编码任务；编码不阻止已经保存的素材查看或普通截图，但不启动第二路录屏或第二个编码任务。

## 5 截图采集与选区

### 5.1 来源与框选

| 编号 | 功能 | 行为要求 |
| --- | --- | --- |
| SC01 | 区域截图 | 在指针所在显示器唤起，先取得冻结画面再显示覆盖层；拖动选区，显示实际输出像素尺寸 |
| SC02 | 松手进入标注 | 有效选区完成后直接显示工具栏；选区位置、大小不跳动，不另开窗口 |
| SC03 | 全屏截图 | 菜单或选区层入口选择当前显示器全部内容，仍允许标注后确认 |
| SC04 | 窗口截图 | 菜单列出可采集窗口；用户选择后得到窗口图片并进入编辑窗；来源消失时返回选择器 |
| SC05 | 选区调整 | 通过 C 或右键菜单进入“调整选区”，拖动边框手柄调整范围，拖动选区内部移动取景范围；该模式暂停对象选择，移动范围不移动标注对象 |
| SC06 | 导入图片 | 菜单导入 PNG、JPEG、WebP；按解码后的实际方向显示，编辑后默认输出 PNG |

无面积选区不进入编辑。松开鼠标得到无效选区时继续等待框选。选区不能跨显示器；用户需要重选屏幕时先退出当前选择，再在目标屏幕唤起。

### 5.2 扩大选区与坐标

本次截图编辑期间允许缩小、扩大或移动选区，但范围不能超过当前冻结显示器。调整范围后仍显示唤起时的冻结画面，不重新采集变化后的桌面。

为支持这一行为，整屏冻结画面仅在本次会话内保留。截图完成后，仅保存最终选区对应的底图和编辑信息；取消时释放整屏缓存。历史截图重开后只能在已保存底图范围内调整，无法找回选区外的桌面。

标注绑定底图像素坐标。修改选区不会移动标注；选区之外的部分在预览和输出中被裁掉。在本次会话内重新扩大选区时，这些部分可以重新出现。选区调整可撤销，且不能提前把标注烘焙进底图。

完成截图时固化底图范围，并把标注坐标转换为相对于最终底图的坐标；重开进入新的编辑会话。旧会话中依赖已释放区域的选区历史不带入，重开的首个画面和标注位置必须与完成时一致。

### 5.3 工具栏布局

一级顺序建议沿用旧版的十三个入口，第五项统一命名为“遮挡”，末项明确为默认确认动作：

```text
形状  线条  画笔  荧光笔  遮挡  文字  橡皮擦  │  撤销  重做  │  取消  贴图  保存  确认
```

工具栏默认位于选区下方靠右位置，空间不足时移到上方或调整水平位置。一级、二级和弹层都必须留在当前显示器的可用范围内。极小选区不压缩工具点击区域，工具栏可以延伸到选区外；冻结画面的内容、选区位置与比例保持不变。空间不足时允许固定顺序换行，不把确认和撤销藏进菜单。

首次框选完成后默认进入选择模式，显示“选择与移动”状态提示，七个绘图工具均不高亮。选择模式通过 `V` 或右键菜单中的“选择与移动”进入；右键菜单同时提供“调整选区”，也可按 C 进入。选区调整和对象编辑各自显示对应手柄，不能同时响应同一次拖动。绘图模式下点击旧对象仍执行当前绘图工具，不偷偷切换为拖动对象。

## 6 截图标注工具

### 6.1 工具规格

以下参数范围和初始值为本版建议。`px` 指底图输出像素，界面缩放不改变其含义。

| 编号 | 工具 | 二级属性顺序 | 创建与编辑行为 |
| --- | --- | --- | --- |
| AN01 | 形状 | 粗细 → 空心或实心 → 矩形或椭圆 → 颜色 | 拖动创建；支持四种组合。空心调整描边，实心仅填充且禁用线宽控件。按 Shift 绘制正方形或圆。创建后可移动、缩放、改样式 |
| AN02 | 线条 | 粗细 → 实线或虚线 → 无箭头或单向或双向 → 颜色 | 拖动创建直线，箭头指向终点；线型和箭头独立组合。Shift 将角度约束到 45 度倍数。可移动整条线或拖动端点 |
| AN03 | 自由画笔 | 粗细 → 颜色 | 连续拖动形成一笔，松手形成一个对象；支持移动、改线宽与颜色、删除。首版不编辑单个路径节点 |
| AN04 | 荧光笔 | 粗细 → 颜色与不透明度 | 与画笔分开记忆参数。同一笔重叠不重复加深；不同笔允许叠色。可移动、改样式、删除 |
| AN05 | 遮挡 | 实色或马赛克 → 对应参数 | 首版以矩形区域创建。实色支持色值且固定完全不透明；马赛克支持方块大小。可移动、缩放、修改参数 |
| AN06 | 文字 | 字号 → 常规或粗体 → 对齐 → 颜色 | 在图片上单击输入，可多行；双击已有文字继续编辑。文字框可调整宽度以换行，高度随内容变化；字号单独修改 |
| AN07 | 橡皮擦 | 整对象擦除提示 | 点击或拖过标注删除整个对象；画笔一整笔是一个对象，文字框整体是一个对象。一轮拖动构成一次撤销操作 |

橡皮擦只删除标注，不修改底图，不擦穿截图，也不删除照片中的原有文字。其提示明确写为“擦除整条标注”。局部擦掉一段笔迹放入 P1。

### 6.2 默认样式与参数

| 项目 | 初始值 | 首版范围 |
| --- | --- | --- |
| 形状 | 红色、空心矩形、3 px、100% 不透明度 | 线宽 1 至 32 px |
| 线条 | 红色、实线、单向箭头、3 px、100% | 线宽 1 至 32 px |
| 画笔 | 红色、3 px、100% | 线宽 1 至 64 px |
| 荧光笔 | 黄色、24 px、30% | 线宽 4 至 96 px |
| 实色遮挡 | 黑色、100% | 可改颜色；不开放不透明度 |
| 马赛克 | 方块边长 12 px | 4 至 48 px |
| 文字 | 系统无衬线字体、24 px、常规、左对齐、红色 | 字号 8 至 128 px；系统字体回退须覆盖中文 |
| 通用不透明度 | 各工具独立 | 1% 至 100%，实色遮挡除外 |

各工具分别记住颜色、线宽、类型和不透明度，应用重开后保留。马赛克和实色遮挡分别记住自己的参数。首版不提供完整字体库或字体安装功能。

### 6.3 颜色选择器

共用颜色组件提供预设色、自定义颜色、十六进制色值输入和适用工具的不透明度调节。预设色至少覆盖黑、白、灰、红、橙、黄、绿、青、蓝、紫，浅色与深色背景下均能识别当前色块。

没有选中对象时，修改参数只改变当前工具后续绘制的样式，并保存为该工具的偏好。选中已有对象时，属性栏反映该对象的实际样式；修改只影响该对象，不改其他对象，也不覆盖该工具的新建默认值。

拖动颜色或透明度时实时预览；修改已选对象时，结束一次调整后形成一次撤销记录。仅修改新建默认样式不进入文档历史，也不清空重做分支。自定义弹层取消或按 Esc 后恢复打开前的值。色值无效时保留原值并提示，不能把无效输入变成黑色或透明。

### 6.4 文字输入

- 点击空白位置进入文字输入；空文本完成后不创建对象。
- 中文输入法组合输入期间，不执行工具切换、删除对象或确认截图。按键优先交给输入法。
- 文本编辑时 Enter 换行，`⌘ / Ctrl + Enter` 完成文字编辑并留在截图界面。完成文字不等于确认截图。
- Esc 取消本次文字修改；已有文字恢复修改前内容，新建未完成文字被移除。
- 文字框支持实际字体度量与自动换行；选中框、命中区域和导出文字位置一致，不能按字符个数估算宽度。
- 删除或替换选中文本使用系统文本编辑规则；复制文本时不能意外复制整张截图。
- 文本编辑中的撤销先作用于文本输入；完成文字编辑时，将整次内容变更合成一条文档历史。已有文本清空后提交视为删除对象，并可撤销。
- 点击确认、保存或贴图按钮时，先完成有效的文字编辑，再执行对应动作；输入法组合尚未完成时不输出半截候选文字。用于结束输入法选词的同一次按键不能再次触发图片确认。

### 6.5 遮挡与绘制顺序

遮挡对底图生效，普通标注在遮挡结果上方绘制，以便在遮挡区域上补说明。马赛克仅从原始底图采样，移动或重叠时不反复降低已经处理过的像素质量；多个马赛克区域按对象顺序处理，实色遮挡最后覆盖底图。

实色遮挡用于把对应区域的原始像素替换为不透明颜色。马赛克是视觉处理，不提供原信息不可恢复的承诺。复制或保存的普通 PNG 只包含最终结果，不附带底图、可移除标注层或可编辑包。

普通标注按创建顺序叠放。首版右键菜单提供“置于顶层”和“置于底层”，仅在普通标注之间调整；遮挡仍保持上述独立规则。这些顺序变化可撤销。遮挡是可选择对象，在它被其他标注覆盖时可通过重复选择或右键候选列表选中。

## 7 对象编辑与撤销

| 编号 | 功能 | 首版规则 |
| --- | --- | --- |
| ED01 | 选择 | 在选择模式中点击命中对象，显示边界与可用手柄；重叠时优先最上层，重复点击同一点可依次切换；空白处取消选择 |
| ED02 | 移动 | 拖动选中对象；方向键每次移动 1 px，Shift 加方向键移动 10 px；按住产生的一次连续调整合为一条历史 |
| ED03 | 调整尺寸 | 矩形、椭圆与遮挡区域显示缩放手柄；线条显示端点；文字只调整框宽与字号；画笔和荧光笔首版仅移动、改样式 |
| ED04 | 修改样式 | 属性栏显示选中对象类型的可用参数；一次连续调整构成一次历史；不支持的属性不出现 |
| ED05 | 删除 | Delete 或 Backspace 删除选中对象，文本输入中保持文字删除行为；右键也提供删除 |
| ED06 | 撤销重做 | 支持创建、移动、尺寸、样式、文字、删除、顺序和选区调整；至少保存本次会话最近 100 次提交的编辑操作 |
| ED07 | 取消手势 | 拖动中按 Esc 或收到指针取消时回到手势开始前的状态，不产生半截对象或历史 |

切换工具、选择对象、移动鼠标、播放视频等临时界面行为不进入文档撤销历史。一次笔画或一次拖动只占一条记录。撤销后发生新编辑，清空重做分支；仅切换工具或查看预览不清空重做。

人和 Agent 的已提交编辑共用同一条历史，历史可标识来源。首版不承诺每个操作者独立撤销自己的修改。重开素材必须恢复编辑对象；跨应用重启保存完整撤销栈放到 P1。

## 8 截图完成与贴图

贴图首版支持拖动、等比缩放、置顶、关闭和重新编辑。开启鼠标穿透前应提示恢复方式；菜单提供“恢复所有贴图交互”，确保用户可以重新操作贴图。关闭贴图不删除已完成素材。贴图操作不自动改写剪贴板，用户仍可从贴图菜单复制图片。

### 9.1 准备设置

| RC01 | 录制范围 | 单显示器矩形区域或全屏；显示实际输出像素尺寸，拖动调整；默认在指针所在显示器打开 |
| RC02 | 麦克风 | 独立开关，首次默认关闭；可选择系统可用输入设备，显示输入活动反馈 |
| RC03 | 系统声音 | 与麦克风独立，首次默认关闭；当前平台不可用时明确禁用，不以无声成功代替 |
| RC04 | 声音组合 | 两者同时开启时录制为一个混合音轨；首版不提供分轨后期编辑 |
| RC05 | 鼠标指针 | 默认显示，平台支持时可关闭；能力不足时说明限制，不忽略设置 |
| RC06 | 开始前检查 | 权限、来源、输入设备、编码可用性和存储位置检查通过后，开始按钮才进入倒计时 |

首版目标帧率为 30 fps，不开放帧率选择器。记住声音偏好和设备选择，准备界面始终展示实际开关；设备消失时要求重选。最近区域只有在原显示器仍存在且范围有效时才能复用。

区域录制的原始录像只包含选定区域；不能先把整屏长期写入文件，直到导出时才裁掉无关部分。录制从倒计时结束后的实时画面开始，不录制准备时的冻结图。

### 9.2 录制与停止

| 编号 | 功能 | 首版要求 |
| --- | --- | --- |
| RC08 | 录制反馈 | 菜单栏显示录制状态；允许时显示小控制条，包含时长和明确的“停止”按钮 |
| RC09 | 控件排除 | 控制条放在录制范围外；无法可靠排除时隐藏浮条，保留菜单和停止快捷键，不能把自己的工具条录进去 |
| RC10 | 停止 | 控制条、菜单、快捷键使用同一停止动作；重复点击无副作用；停止后进入收尾，不能立即剪辑 |
| RC11 | 收尾 | 等待最终数据写入，完成必要校验；普通主动停止后打开编辑窗，默认暂停在第一段起点；退出和主动收起的情况按下文处理 |
| RC12 | 中断 | 来源消失、显示器断开、磁盘写入失败等情况结束采集，保留已写入内容，区分“可恢复素材”和“没有可用素材” |

录制期间 Esc 不作为全局停止键，以免干扰被录制应用。首版不提供暂停和继续。正在录制时退出应用，给出“停止并保留后退出”和“继续录制”两种选择。

选择“停止并保留后退出”时，收尾完成后直接退出，不再打开编辑窗；若收尾失败，显示结果并保留能恢复的数据。收尾中主动收起状态界面后，完成只提示素材已就绪，用户可从最近记录打开。异常中断也只提示恢复入口，不强行打开编辑窗。

显示器分辨率或缩放在录制中发生变化时停止并保留已有内容，说明原因；不悄悄切换区域、屏幕或输出比例。音频来源失效时停止并保留已有内容，提示音频中断，不继续显示完全正常的录制状态。

## 10 视频预览与轻剪辑

### 10.1 编辑窗与播放

编辑窗包含播放器、单轨时间线、剪辑工具和默认确认按钮。首版只编辑一份录制素材，不拼接其他文件，不重排素材中的片段。

| 编号 | 功能 | 首版要求 |
| --- | --- | --- |
| VE01 | 播放 | 播放、暂停、定位、拖动进度；首次打开不自动出声；播放到输出结尾后暂停 |
| VE02 | 时间显示 | 时间线标注“原片时间”，播放器标注“成片时间”；同时展示原片时长与成片时长，避免混淆 |
| VE03 | 预览一致 | 按保留顺序播放，跳过删除区间，应用当前裁切和静音；不能仅在导出时才体现编辑 |
| VE04 | 定位反馈 | 拖动后显示对应画面；尚未完成解码时显示定位中，不以旧画面冒充新时间点 |

原片时间线上，被删除和首尾排除的部分有明确视觉区别。预览播放头在跳过区间时同步更新。定位到已删除区间时，定位至其后的第一个保留画面；若之后没有保留片段，则定位至最后一个保留画面，并显示最终位置。

### 10.2 剪辑工具

| 编号 | 功能 | 操作方式 | 规则 |
| --- | --- | --- | --- |
| VE05 | 首尾裁剪 | 拖动左右手柄，或输入开始与结束时间；可用“设为起点”和“设为终点” | 确定整份素材的保留边界；两端不能颠倒或产生空输出 |
| VE06 | 中段删除 | 在原片时间线上选择区间，点击“删除片段”；允许重复执行 | 可形成多个删除区间；相邻或重叠区间合并；保留片段按原顺序连接 |
| VE07 | 画面裁切 | 在预览上拖动矩形、调整手柄；提供原始比例、自由比例及像素尺寸输入 | 全片应用同一个裁切框；范围不超出原画面；点击应用后提交一次编辑 |
| VE08 | 静音 | 一个全片静音开关 | 保留原音频数据，关闭静音可恢复；无音频素材禁用并提示 |
| VE09 | 撤销重做 | 工具按钮或编辑快捷键 | 覆盖首尾、删除区间、画面裁切、静音；一次手柄拖动为一次编辑 |
| VE10 | 重置编辑 | 次要菜单中的“恢复原始剪辑” | 将首尾、删除、裁切和静音一起恢复初始值；作为一次可撤销操作，不删除素材 |

内部时间计算保持精确，显示可用毫秒；剪切边界按可输出的视频帧对齐，预览和导出使用相同结果。不能把用户输入的时间精度描述为无限精度剪辑。超出时长、负数或无效数值立即提示，提交前保留之前有效结果。

画面裁切按整数像素处理；若编码格式要求偶数尺寸，应在应用裁切时显示并采用最终有效尺寸，预览同步更新，不能到导出时才悄悄改变区域。

首尾范围变化不会销毁已记录的中段删除区间；重新扩大首尾范围后仍应用其交集。撤销中段删除可恢复该部分。所有片段被删空时拒绝该操作并提示“至少保留一段内容”，保持最后一个有效编辑状态。

### 10.3 下一阶段视频标注

文字、箭头和矩形遮挡列入 P1，不影响首版交付。后续每个标注需要定义开始与结束时间、画面位置、样式和撤销行为；静态位置不等于跟踪运动对象。视频缩放、裁切和删片段后如何映射标注时间，需在该阶段另行评审。

## 11 确认复制视频与文件管理

### 11.1 默认确认流程

```text
确认并复制
→ 固定本次编辑版本
→ 生成 MP4 文件
→ 校验输出
→ 写入系统文件剪贴板
→ 提示视频文件已复制
→ 收起编辑窗
```

| 编号 | 要求 | 具体行为 |
| --- | --- | --- |
| CL01 | 默认无需选目录 | 确认后写入应用管理的持久导出目录，不先弹出保存对话框 |
| CL02 | 复制真实文件 | 剪贴板承载可粘贴的 MP4 文件引用或平台等效文件格式，不以路径文本冒充文件 |
| CL03 | 成功条件 | 编码成功、输出有效且文件剪贴板写入成功，才显示完成并收起窗口 |
| CL04 | 复制失败 | 编码成功但复制失败时保留 MP4、编辑状态和错误提示；提供“重试复制”与“显示文件位置”，不重新编码未变化的结果 |
| CL05 | 取消编码 | 取消后回到编辑，保留原件与剪辑草稿，删除未完成输出；取消本次任务不清空剪贴板 |
| CL06 | 失败重试 | 显示可理解的原因，如空间不足、素材不可读或编码失败；保留输入和草稿，修复条件后重试 |
| CL07 | 文件寿命 | 关闭窗口、退出应用、下一次录制或导出均不删除已复制文件；不把它当临时缓存自动清理 |
| CL08 | 次要动作 | “另存为”选择用户目录；“显示文件位置”定位文件；“复制路径”使用明确的独立名称 |
| CL09 | 保护新的剪贴板内容 | 确认时记录剪贴板变化标识；编码期间用户或其他应用有新的复制操作，完成后改为“视频已生成，点击复制”，不覆盖新内容 |

确认过程中冻结该文档的编辑入口，显示阶段与进度；重复确认不生成重复任务。用户可以取消后继续编辑。编码期间关闭编辑窗只收起窗口，任务继续，菜单可重新打开；失败时通过菜单状态提示，不强制抢焦点。

输出校验至少检查容器、音视频轨、时长是否符合编辑计划，以及首尾画面能否解码；文件非空或编码进程退出并不足以独立证明输出成功。

剪贴板未变化时仍按默认流程自动复制。CL09 只检测变化，不读取或保存其他应用复制的内容；需要再次复制时，前台编辑窗保留明确按钮，已收起的窗口使用菜单提示，不强制弹出。用户可以点击复制，或返回编辑后重新确认。

退出应用时若仍在编码，提供“取消导出并退出”和“继续等待”。应用异常退出后的未完成输出不得显示成已完成文件。

### 11.2 输出规格

| 项目 | 首版建议 |
| --- | --- |
| 格式 | MP4，优先使用目标平台验证过的 H.264 视频与 AAC 音频组合 |
| 默认预设 | 适合分享；最长画面宽度上限 1280 px，保持比例，不放大小素材 |
| 可选预设 | 更清晰；宽度上限 1920 px，保持比例，不放大小素材 |
| 大小提示 | 分享预设默认以 25 MiB 估算预算；显示预计大小，完成后显示实际大小，不承诺硬上限 |
| 超出预算 | 明确提示预计超出，允许调整预设、缩短内容或仍然确认；不静默删片段 |
| 文件名 | 时间与唯一后缀组合，避免覆盖原件或已有导出 |

确认复制后可以再次打开原稿修改，下一次确认生成独立的文件版本。已有文件若仍可能被剪贴板或其他应用引用，应持续可访问。

系统文件剪贴板不支持或写入失败时，显示准确限制并提供保存或显示位置，不能显示“已复制视频”掩盖降级。系统写入成功即可显示“视频文件已复制”，不代表所有目标应用都会接受粘贴；具体聊天应用的兼容性在验收记录和帮助中说明，不能在复制时声称已检查尚未选择的粘贴目标。

## 12 最近记录与恢复

| 编号 | 场景 | 首版行为 |
| --- | --- | --- |
| DA01 | 新截图未完成 | 临时保留在当前会话；取消后释放，不加入最近记录；不承诺崩溃后恢复未确认截图 |
| DA02 | 截图已完成 | 保存最终选区底图、标注与裁剪状态，可重开编辑；默认普通 PNG 输出不包含这些内部数据 |
| DA03 | 视频已录完 | 原件与剪辑草稿分别保存，关闭预览不删除；重新录制不覆盖旧素材 |
| DA04 | 采集中断 | 下次启动提示有未完成录制，提供检查恢复、显示原件、删除入口；无法修复时说明原因 |
| DA05 | 最近记录 | 展示缩略图、类型、时间、时长或尺寸及草稿状态；可打开、显示位置和删除，不默认打开大型图库 |
| DA06 | 存储管理 | 展示原件与导出占用；首版仅由用户明确清理，默认不做自动过期删除 |
| DA07 | 删除 | 区分删除编辑原件和删除导出文件；删除前说明影响，最近复制文件需提醒可能影响尚未完成的粘贴 |

历史截图的编辑在操作提交后保存。完成素材的删除属于明确操作，关闭窗口、按 Esc、导出失败和重新录制都不等于删除。

采集、收尾、编码、校验或复制事务正在使用的原件、草稿及输出不可删除；清理入口说明需要先停止或取消相关任务。事务结束后才允许明确清理，不能让最近记录的删除破坏正在进行的操作。

## 13 Agent 协作

Agent 通过工具接口操作同一份素材，默认静默。只有主动请求展示或贴图时才打开界面，不因截图、添加标注或导出抢走用户焦点。

| 编号 | 能力 | 首版行为 |
| --- | --- | --- |
| AG01 | 发现与采集 | 列出有效来源，选择来源或区域截图，返回截图标识、实际尺寸及预览 |
| AG02 | 接续编辑 | 读取当前人工截图会话及版本，添加或修改 P0 标注、裁剪、撤销与重做 |
| AG03 | 版本冲突 | 修改带预期版本；版本过期时拒绝并返回最新版本信息，不覆盖用户修改 |
| AG04 | 人机同步 | 人与 Agent 的已提交修改即时反映在同一编辑状态；人工拖动中的本地预览不被静默覆盖 |
| AG05 | 展示与交接 | 显式展示时优先定位现有截图层；贴图产生置顶图片，不另造专门的 Agent 工作台 |
| AG06 | 输出 | 预览、PNG 导出与复制使用相同绘制结果；默认不顺带输出未遮挡底图或可编辑包 |

Agent 普通复制只改写剪贴板，不关闭正在由人操作的编辑层；人工“确认”才结束人工截图会话。Agent 与人工同时编辑时，先按文档版本串行提交；冲突后重新读取再操作。

首版可以沿用现有 MCP 传输方式。录屏启动、停止和视频编辑工具放入 P1，届时明确会话归属与停止语义。产品不内置模型服务，也不要求用户登录云账号才能采集、编辑或导出。

## 14 快捷键与取消规则

### 14.1 默认快捷键建议

下表 `Mod` 表示 macOS 的 Command，Windows 和 Linux 的 Control。全局快捷键可以在设置中修改；注册失败时说明冲突并保留菜单入口。

| 作用域 | 操作 | 默认键位 |
| --- | --- | --- |
| 全局 | 截图 | Mod + Shift + 1 |
| 全局 | 录屏 | Mod + Shift + 2 |
| 全局 | 停止录制 | Mod + Shift + X |
| 截图编辑 | 选择与移动 | V |
| 截图编辑 | 调整选区 | C |
| 截图编辑 | 形状、线条、画笔、荧光笔 | R、A、P、H |
| 截图编辑 | 遮挡、文字、橡皮擦 | B、T、E |
| 编辑器 | 撤销、重做 | Mod + Z、Mod + Shift + Z；Windows 和 Linux 额外支持 Ctrl + Y |
| 截图编辑 | 确认复制 | Enter 或 Mod + C，焦点在画布或编辑器空白处且无未完成手势时 |
| 截图编辑 | 保存图片 | Mod + S，先完成当前文字编辑 |
| 文字编辑 | 换行、完成文字 | Enter、Mod + Enter |
| 视频编辑 | 播放或暂停 | Space，焦点在播放器、时间线或编辑器空白处时 |
| 视频编辑 | 前后定位 | 左右方向键各 1 秒，Shift 加方向键各 5 秒，焦点在播放器或时间线时 |
| 视频编辑 | 确认并复制 | Enter，焦点在播放器、时间线或编辑器空白处且无未完成拖动时 |
| 当前编辑器 | 取消局部操作 | Esc，按下表分层处理 |

输入框、数字字段和中文输入法拥有文字按键的优先权。Enter 在数字输入中仅提交该字段，不触发整个截图或视频确认。编辑文字时 Mod + C 复制选中文本，Delete 删除文字。

按钮、菜单项、列表和弹层也优先处理自身按键。焦点在“删除片段”“保存”或“取消”等按钮时，Enter 或 Space 激活该按钮，不能被编辑器拦截为确认或播放。事件处理后不继续冒泡执行第二项操作。

### 14.2 Esc 与关闭行为

| 当前状态 | Esc 行为 | 关闭界面的行为 |
| --- | --- | --- |
| 截图正在框选 | 取消新截图 | 同左 |
| 截图正在拖动、输入文字或打开弹层 | 先取消当前局部操作，恢复局部操作前状态 | 先结束局部操作，再按新截图或历史素材规则处理 |
| 截图选中对象 | 取消对象选择，保留截图 | 新截图关闭即取消；历史编辑关闭保留已提交操作 |
| 截图普通标注状态 | 取消本次新截图；历史编辑只收起 | 同左 |
| 录制准备 | 退出准备回到待命 | 同左 |
| 倒计时 | 返回录制准备 | 返回录制准备 |
| 正在录制 | 不处理其他应用收到的 Esc | 控制条关闭视为停止请求，先收尾；退出应用另行确认 |
| 正在收尾 | 不终止已经写入的数据处理 | 可收起状态界面，后台继续 |
| 视频局部编辑 | 取消当前拖动、输入或弹层 | 保留已提交草稿 |
| 视频普通预览 | 收起编辑窗并保留草稿 | 同左 |
| 正在编码 | Esc 不直接终止；使用明确的取消按钮 | 收起界面，任务继续，菜单可重开 |

## 15 跨平台与质量要求

### 15.1 平台能力边界

共用产品逻辑包括素材、标注、命令、剪辑计划、撤销历史、交互状态和文案。平台适配处理采集来源、屏幕坐标转换、权限、窗口行为、声音、快捷键、剪贴板文件格式和文件选择器。

| 能力 | 每个平台必须验证 |
| --- | --- |
| 采集 | 区域是否准确、全屏与窗口来源、实际分辨率、指针、排除自身界面 |
| 多屏 | 不同缩放、负坐标显示器、屏幕切换、断开与重连；首版单次只选一屏 |
| 声音 | 麦克风、系统声音、组合录制、权限拒绝、设备中断 |
| 桌面交互 | 托盘、全局快捷键、置顶、鼠标穿透与恢复、全屏应用上的覆盖层 |
| 剪贴板 | 图片粘贴、MP4 文件粘贴、退出应用后仍可粘贴；路径复制独立验证 |
| 文件与分发 | 保存对话框、非 ASCII 路径、空间不足、安装包权限和媒体组件可用性 |

macOS 通过不等于 Windows 或 Linux 通过。Linux 发布需明确桌面会话与显示协议的验收组合；未支持能力准确标示。文件剪贴板不可用的平台不能宣称默认视频确认流程已完整支持。

### 15.2 质量验收目标

以下为首版目标，测试记录需注明硬件、系统、显示器缩放、应用版本与样本。

- 图片输出尺寸与选区显示值一致；预览和导出的标注位置、裁切与遮挡一致。在相同渲染环境下比较像素结果，不用肉眼大致相同代替。
- 以一张 3840 × 2160 图片及 100 个普通标注为基准，持续拖动与绘制不出现超过 100 ms 的明显操作停顿；若超标，记录瓶颈并在交付前解决。
- 连续录制 10 分钟、目标 1080p 30 fps，内存占用应趋于稳定；需要记录实际帧率和音画同步。首尾及拼接处的音画偏差目标不超过 100 ms。
- 视频输出片段边界与预览的差异不超过一个目标视频帧；像素编码变化可以存在，保留区间、裁切和静音不能不同。
- 完成与取消路径反复执行后，不遗留阻挡用户操作的透明窗口，不保留失效的麦克风或屏幕采集状态。
- 图片与视频工作流均可通过键盘完成主要动作；焦点可见，状态不能只用颜色表达。
- 正式应用包应自带或自动管理必需的媒体运行组件，普通用户不需安装 MoonBit、Node 或手动配置 FFmpeg；开发环境要求另行说明。

本版优先评审三个新增设计取舍：

1. 截图沿用十三入口，第五项为“遮挡”，包含实色与马赛克；橡皮擦首版删除整对象。
2. 本次截图会话允许扩大选区，完成后只保存最终选区底图；历史重开无法恢复选区外画面。
3. 最近记录默认保留完成素材与视频草稿，导出文件由用户明确清理，以保证复制后的文件持续可用。

视频标注延后、默认确认复制、截图与录屏的独立入口、跨平台方向和 UI 不限定语法均已确认，不作为待定问题重复评审。
