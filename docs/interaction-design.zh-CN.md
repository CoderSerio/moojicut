# 截图编辑与录屏体验

本轮围绕两个完整流程组织界面：截图后编辑并复制；录制后预览、剪辑并保存。常用操作直接可见，相关但不常用的参数按需展开。macOS 截图与设置仍采用原生控件；正式视频编辑窗已改为共享 MoonBit UI，由 AppKit 通用画布接入输入、绘制和系统辅助功能。

2026-11-16 状态：macOS 视频编辑器的布局、外观和交互已共用一套 MoonBit 代码，底层窗口、输入、渲染和媒体能力由系统适配提供。以下平台实现是现状记录；后续复杂组件与拆库遵循[共享编辑组件约定](shared-editor-ui.zh-CN.md)，不将 AppKit 控件逐端重写作为新组件的实现方向。

## 交互约定

| 场景 | 行为 |
| --- | --- |
| 截图工具栏 | 只有两组和一条分割线：左侧标注/用户工具、OCR/翻译、撤销/重做；右侧贴图、取消、完成。工具和操作共用尺寸、间距与单按钮高亮。浮层随可见工具及属性调整宽度；空间不足时横向滚动。滚动截图入口保持隐藏和禁用。 |
| 选择标注 | 点击矩形边框、箭头、文字或遮挡选中对象；拖动移动，控制点调整尺寸，Delete 删除；每次手势作为一次可撤销操作。已有选中矩形可从内部拖动。 |
| 截图选区与标注 | 截图范围使用原来的圆形控制点，标注使用方形控制点；箭头只显示两端点，避免把方向丢失成普通矩形。遮挡保持最上绘制与命中优先级。 |
| 调整颜色 | 属性行只显示颜色色块和适用的字号/线宽；色块展开常用色、不透明度数值和滑条、更多颜色。颜色与透明度一起改变当前对象或当前工具默认值。 |
| 识别与翻译 | 工具栏只有一个文字入口。统一窗口默认展示可校对原文，按需翻译，切换原文/译文；一个复制按钮始终对应当前内容。 |
| 更新 | 版本头、更新状态和主要操作集中排列，下方是自动检查选项。长错误有界滚动，主按钮保持可见。 |
| 快捷键 | 默认显示“截图与录屏”，直接列出开始截图、开始录屏和停止录屏；贴图单独分类。三行按键控件对齐。无关的运行机制说明不占据常态界面。 |
| 录屏 | 直接框选区域或悬停识别窗口，右下确认后显示 3 秒圆环倒计时，下方可取消；菜单栏显示时长和停止入口，完成编码后再打开编辑器。 |
| 录后编辑 | 共享图标工具栏、预览与多片段时间轴；支持切分、按钮调序、片段变速、音轨展开/解除和独立偏移。时间轴通过快捷键或修饰键滚轮缩放，方向键逐帧定位。片段裁剪只改草稿与预览，保持时间轴比例，允许重新拉回边界；保存时才编码。全片静音与画面裁剪可撤销；裁剪先预览再应用，取消不改文档。保存 MP4 保留原片和草稿。 |

切换工具、关闭弹层或复制前，正在输入的数字和中文组合文本需要先完成或明确取消。无效输入不会悄悄变成另一个数值。移动、缩放、颜色滑条等连续手势只形成一个撤销步骤。

文字服务只处理当前截图内容。修改原文或语言后旧译文失效；取消、关闭、切换截图或迟到回复不会覆盖新任务。剪贴板只在显式复制时写入。

## MoonBit 与原生边界

MoonBit 核心继续编译为原生静态库，与平台程序链接；用户插件的 Wasm 运行时是独立的扩展机制。

| 规则 | MoonBit | 原生宿主 |
| --- | --- | --- |
| 图像编辑 | 文档、历史、样式、对象命中、箭头翼端点与几何变换 | 鼠标事件、屏幕与图片坐标映射、绘制、TextKit 字形测量和输入法 |
| 快捷键 | 必需组合键、保存值恢复、显式停用、重复冲突、原子修改 | 物理键与键盘布局、系统保留组合查询、注册和偏好持久化 |
| 贴图 | 缩放/不透明度限值与可见恢复等数值规则 | 窗口、事件、位置映射、穿透和系统快捷键 |
| 录屏 | 状态转换、允许操作、平台编码尺寸与帧率配置 | 桌面覆盖层、窗口枚举、权限、时钟、ScreenCaptureKit 和真实采集句柄；选区手势复用截图的共享几何规则 |
| 视频编辑 | UI 布局/图标/命中/手势、时间线、链接/变速、静音/裁剪、撤销、草稿数据和导出计划 | 通用画布与视频表面、AVPlayer/AVComposition、编码、文件校验及原子写入 |
| 插件与更新 | 清单/调用协议、工具目录和排序、版本与资产选择 | ZIP 解码和路径边界、文件锁、独立 worker、网络、签名和安装 |

共享规则通过已有或新增 C ABI 被实际调用。保留每个平台原有能力上限，不能因为共用配置函数就把 macOS 的录制规格套到 Windows。

截图与录屏的 macOS 桌面选区共用 `components/selection/macos/`：边界手势、首击响应、内容坐标映射、选区绘制、窗口配置和快捷键释放等待。几何继续调用 `src/internal/shared/geometry` 的 MoonBit 实现。`components/desktop_capture/macos/` 统一生成冻结底图；所有屏幕就绪后才显示窗口，取消与迟到回调通过会话代次隔离。截图保留标注和导出行为，录屏只附加窗口候选、声音开关与录制确认。

## 录屏 MVP 范围

macOS 继续要求应用既定的 macOS 26。直接桌面覆盖层支持任意矩形区域、完整显示器或单个窗口；窗口模式使用独立窗口流，移动窗口仍跟随，区域流使用显示器局部点坐标的 `sourceRect`；编码 H.264/MP4，保留比例、最长边不超过 3840 像素、30 fps，可录系统声音，保留鼠标指针。不提供麦克风或暂停。

Windows 保留主显示器、最高 1920×1080、15 fps、无声录制及旧编辑宿主。Linux 尚未提供录屏或视频编辑；两个平台尚未接入新的共享视频界面与媒体链。

取消启动、迟到的采集回调和停止后的文件收尾分别处理。只有录制输出完成回调后才能进入视频编辑；失败时保留可恢复的原片。导出先写同目录临时文件，再校验和替换目标，取消或失败不破坏已有目标。

macOS 的录制完成与恢复草稿入口进入同一共享编辑窗。新草稿写入 `edit-v2.json`，原片和旧 `edit.json` 保留。已有 v2 无法读取或格式损坏时不回退旧版；仅缺少 v2 时读取旧草稿并迁移。恢复最近草稿按时间跳过无效候选，不弹出一串错误或改写文件；没有有效草稿才提示。草稿写入失败会保留内存编辑，并阻止关闭、退出和导出，修复后可以重试。

## 验证边界

- MoonBit 测试覆盖纯规则、非法输入、撤销/状态边界和平台差异。
- 原生交互测试覆盖 AppKit 控件及共享画布输入、布局、取消和迟到回调；正式视频接入测试还覆盖严格 v2 恢复、旧文件保留、写入失败后的重试和退出保护。
- 媒体测试实际创建、裁剪、导出并重新解码 MP4，核对时长、尺寸和音轨。
- 浅色、深色及长错误布局使用实际 AppKit/共享画布渲染检查。
- 真实桌面选区、窗口跟随、权限、屏幕录制和声音、原生视频预览、应用内更新须分别实机验证；隐藏窗口和合成视频不能替代这些步骤。
