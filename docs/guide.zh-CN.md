# Mooji Cut 使用与构建指南

[English overview](../README.en.md) · [返回中文首页](../README.md)

本指南介绍当前源码开发候选 `0.1.0-alpha.14` 的能力。已发布的安装包可能尚未包含这些功能；安装前请先查看对应版本的[发布说明](https://github.com/CoderSerio/moojicut/releases)。

## 下载与开始使用

前往 [发布页](https://github.com/CoderSerio/moojicut/releases)，选择已提供的安装包，并核对该版本的功能范围与运行要求。发布包随附 SHA256 校验文件。下表说明开发版的运行方式；若尚无适用的发布包，可参考下方的源码构建说明。

| 系统 | 运行要求 | 打开方式 |
| --- | --- | --- |
| Windows | Windows 10/11，Intel / AMD x64 | 解压 ZIP，双击 `MoojiCut.exe`，从任务栏托盘菜单开始截图或录屏 |
| macOS | Apple Silicon，macOS 26.0 或更新版本 | 解压 ZIP，将 Mooji Cut 放入「应用程序」并打开，从菜单栏图标进入 |
| Linux | Ubuntu 22.04/24.04 x86_64 及兼容发行版，glibc ≥ 2.35 | 解压 tar.gz，在目录中运行 `./launch.sh`，打开设置后点击「截图并标注」 |

下载的应用无需安装 MoonBit 或 Python。关闭设置会继续在后台待命；完全退出请使用菜单栏或托盘中的「退出 Mooji Cut」。

Windows 包免安装，目前尚未进行代码签名，系统可能显示未知发布者提示。macOS 预览包尚未完成 Apple 公证，首次打开可能需要在「系统设置 → 隐私与安全性」中确认。

Linux 需要 GTK 3、Ayatana AppIndicator 和 libcurl。Ubuntu 22.04 可运行：

```sh
sudo apt install libgtk-3-0 libayatana-appindicator3-1 libcurl4
```

部分 GNOME 桌面需要 AppIndicator 扩展才能显示托盘；没有图标也可运行 `./launch.sh` 打开设置，或运行 `./moojicut --capture` 直接截图。Wayland 还需要桌面提供可用的 `xdg-desktop-portal` 截图服务。

## 截图：标出重点，再发出去

框选后可直接原地标注，在画布中输入和重新编辑文字，并调整位置、大小、颜色与字号。工具栏第二行显示当前工具的属性：字号与线宽可通过数值控件或上下箭头调节；文字、矩形、箭头和填充覆盖均提供颜色与不透明度控件。Wayland 通过门户取得图片后进入无边框编辑界面，定位与置顶效果取决于桌面合成器。

属性控件使用同一套交互，各工具的样式分别保存：在本次编辑中切换文字、矩形、箭头或填充覆盖，会恢复该工具上次使用的颜色、不透明度及适用的字号或线宽。选中已有标注后修改属性，只影响该标注；取消选择或重新切换工具，就会回到新建标注的默认样式。

macOS 的浮动工具栏按当前工具与属性控件调整宽度，启停插件或切换工具后会重新排布；空间不足时可横向滚动工具行。绘图光标仅用于画布操作，移到工具栏按钮上会恢复普通指针，文字输入框使用文字光标。

**框选 → 标注 → 确认 → 复制图片**

1. 从菜单启动截图，或使用默认快捷键。
2. 选好区域后，添加矩形、箭头、文字或填充覆盖。需要完全盖住原图内容时，将覆盖的不透明度设为 100%。
3. 不满意可撤销或重做。点击复制后，将保留原图尺寸的图片放入剪贴板。
4. 回到聊天或文档中粘贴。按 `Esc` 或取消会关闭本次编辑，保留原有剪贴板内容。

首次在 macOS 截图时，需要允许「隐私与安全性 → 屏幕与系统音频录制」权限；授权后按系统提示重新打开应用。Wayland 的截图选择与授权由系统门户处理，取消授权不会替换剪贴板。

## 文字识别与翻译（macOS）

选好截图区域后，在工具栏点击「文字识别（OCR）」或「翻译」。文字识别会打开结果窗口；翻译会先识别截图中的文字，再生成译文。两者处理的是当前截图内容，包括已有标注。

识别结果和译文都可以修改。可选择源语言与目标语言；自动识别原文语言失败时，手动选择源语言后重试。修改原文或语言后，点击「翻译」重新生成译文。需要重新读取这张截图时，点击「重新识别」；需要中止处理时，点击「取消任务」。只有点击「复制原文」或「复制译文」才会改变剪贴板。

文字识别与翻译均在本机处理。翻译使用 macOS 支持的语言组合；首次使用某些语言时，需要联网并在系统弹窗中允许下载语言资源。下载未完成、所选语言组合不受支持或系统无法识别原文语言时，窗口会提示原因。Windows 与 Linux 目前尚未接入这两项功能。

## 滚动截图（暂时关闭）

滚动截图仍需修复，当前版本默认不显示工具栏入口。待真实页面拼接和交互完成修复、验证后再开放。

## 插件管理：选择工具和导入插件

macOS 开发版提供「设置 → 插件管理」。在「截图工具」分类中，可分别启用或停用矩形、箭头、文字、遮挡（填充覆盖）和贴图；选中一项后，点击「上移」或「下移」调整顺序。这些工具在截图工具栏中按设置顺序显示，停用的工具会从工具栏中隐藏。启用状态和顺序自动保存，重新打开应用后仍会保留。

停用标注工具不会删除画面中已有的标注。贴图开关与「设置 → 通用」中的「启用贴图」双向同步；关闭贴图会移除现有贴图并释放贴图快捷键，详见下节。

用户插件宿主目前仅在 macOS Apple Silicon 上验证。Windows 与 Linux 的既有应用功能和共享编辑核心保持上表所列范围，尚未接入用户插件与此管理界面。「录制控制」和「录后编辑」分类目前暂无可管理项。

**导入 ZIP → 管理工具 → 截图工具栏调用 → 查看并复制文本**

1. 在「设置 → 插件管理」中点击「导入插件…」，选择作者提供的预编译插件 ZIP。应用会检查插件包并试运行其中的工具；导入时无需安装 MoonBit，也不会编译插件源码。
2. 导入成功后，在「截图工具」列表中逐项启用或停用新增工具，选中一项后用「上移」「下移」调整顺序。新工具追加在列表末尾，顺序和开关自动保存。
3. 启动截图并选好区域，从截图工具栏点击插件工具。例如 Capture Info 示例提供「截图信息」和「查看尺寸」。
4. 在结果窗口查看纯文本，需要时点击「复制文本」。包括「查看尺寸」在内，插件调用本身不会自动写入剪贴板。

当前插件只接收截图的宽、高、PNG 格式和修订号，不接收图像像素、文件路径或剪贴板内容；只可返回文本，不支持网络访问、文件访问或自定义界面。导入时的试运行使用合成截图信息，不传入用户截图。重新打开应用会恢复已安装插件与工具偏好，不会自动运行插件。

导入相同插件的新 ZIP 可替换已安装版本，保留相同工具的顺序和开关。通过「卸载插件…」可移除该插件的全部工具并取消正在运行的调用；重新安装相同工具 ID 可恢复原偏好。卸载不会删除已有截图标注，也不保证立即回收旧插件包占用的磁盘空间。

## 贴图：留在原处，随时参考

点击图钉，编辑结果会固定在当前截图的位置和尺寸。拖动可以移动；双击关闭，或单击选中后按 `Esc` 关闭。选中贴图后用 `+` / `-` 缩放，用 `⌘`（macOS）或 `Ctrl`（Windows / Linux）配合 `+` / `-` 调整不透明度。

macOS 再次截图时，可见的贴图会留在画面中，可以把之前固定的图片一起框选进去；主动隐藏的贴图仍保持隐藏。

隐藏/恢复默认使用 macOS 的 `⌘ ⇧ H`，Windows / Linux X11 使用 `Ctrl + Shift + H`。有选中贴图时切换当前贴图；未选中时，若有隐藏项就恢复隐藏项，否则隐藏全部。恢复会保留此前的不透明度。

鼠标穿透默认使用 macOS 的 `⌘ ⇧ P`，Windows / Linux X11 使用 `Ctrl + Shift + P`。穿透期间保留选中目标，鼠标交给下面的应用；贴图不会响应缩放、隐藏、Esc 或双击关闭，再按同一组合解除。应用只有在恢复快捷键可用时才允许进入穿透。也可以从菜单栏或托盘选择“恢复隐藏贴图”或“解除鼠标穿透”。Wayland 暂不启用鼠标穿透。

以上按键均可在贴图快捷键设置中修改。隐藏与穿透的恢复键需要组合键，方便切到其他应用后仍能找回贴图。

在「设置 → 通用」中可关闭贴图功能。关闭会立即移除现有贴图（包括隐藏和穿透中的贴图），释放贴图快捷键，截图编辑仍可继续。重新开启后即可创建新贴图，原来的快捷键配置会保留；已关闭的图片不会重新出现。

## 录屏：剪掉多余，再分享过程

**开始录制 → 停止 → 编辑 → 确认并复制视频文件**

macOS 可以在开始时选择是否录制系统声音，再通过系统界面选择显示器或窗口。Windows 当前录制主显示器，保留画面比例，最高 1080p、15 fps，包含鼠标指针但没有声音。

结束录制后进入编辑器。按原片的时间填写保留范围或删除区间，点击对应的应用按钮；也可以指定画面范围，去掉不需要的边缘。编辑支持撤销、重做与预览。macOS 有音轨的录屏还可以选择静音。

确认后生成 MP4，并将**视频文件**放到剪贴板，供支持文件粘贴的应用接收。只预览或取消编辑不会复制视频。关闭编辑器会保留原片与草稿；macOS 和 Windows 可从菜单「继续编辑上次录屏」重新打开。

录屏文件保存在本机：macOS 位于 `~/Library/Application Support/MoojiCut/`，Windows 位于 `%LOCALAPPDATA%\MoojiCut\`。`Drafts` 保存原片和编辑草稿，`Exports` 保存确认后的成片。

## 快捷键

| 操作 | macOS 默认 | Windows 默认 |
| --- | --- | --- |
| 截图 | `⌘ ⇧ 1` | `Ctrl + Shift + 1` |
| 开始录屏 | `⌘ ⇧ 2` | `Ctrl + Shift + 2` |
| 停止录屏并编辑 | `⌘ ⇧ X` | `Ctrl + Shift + X` |

在「设置 → 快捷键」中可以录入新组合、清除或恢复默认。若组合已被系统或其他应用占用，换一个组合即可；录入期间会暂时停用对应的全局响应。Linux 当前保存的快捷键尚不会触发采集。

## 应用内更新

在「设置 → 更新」中检查 GitHub Releases，无需登录 GitHub。开发预览版会接收更新的预览版和正式版；正式版只接收正式更新，不会自动降级。检查失败、网络超时或 GitHub 限流时会显示原因，稍后可重试。

macOS 请将正式应用放在 `/Applications/Mooji Cut.app`，之后从「设置 → 更新 → 检查更新」下载、安装并重新打开，更新会替换原位置的应用。更新信息和安装包均按应用内置公钥校验。如果该版本还没有签名源，设置会提示打开发布页手动下载。默认手动检查，也可以开启自动检查，应用不会静默安装。截图或录屏编辑尚未结束时，会等待你完成当前操作。下载时可以取消；验证失败不会安装该更新。

Windows 与 Linux 可在更新页下载对应平台的安装包，校验大小及 SHA256 后保存到选择的位置；下载可以取消，失败时不会覆盖已有文件。下载完成后点击打开文件位置，退出旧版本，再手动解压并运行新版本。这两个平台目前尚不支持自动替换正在运行的应用。

更新沿用原有的快捷键、偏好设置和录屏草稿存储位置。首次安装仍需下载应用；旧版若没有更新入口或提示更新源不可用，可从发布页手动换装。预览版的真实覆盖安装与设置保留验收情况，以对应版本发布说明为准。

## 从源码构建

准备支持 native 静态库的 MoonBit 工具链和 Python 3.12 或更新版本；Windows / Linux 的 CI 固定使用 MoonBit `0.10.20+65efd5b93`。

- macOS：Xcode Command Line Tools 及支持 macOS 26 的 SDK。
- Windows：MSVC C++ Build Tools 与 Windows SDK，在 x64 Native Tools 开发终端中运行。
- Linux：C 编译器、`pkg-config`、GTK 3、Ayatana AppIndicator 和 libcurl 开发包。

在仓库根目录运行：

```sh
python3 scripts/desktop.py dev
```

Windows 可将 `python3` 换成 `python`；macOS 与 Linux 也可使用 `make dev`。构建后会启动应用并打开设置。

macOS 首次构建会下载并校验固定版本的 Sparkle 更新框架和 Extism 插件运行时。开发构建名为 `Mooji Cut Test …`，使用独立应用身份、偏好、插件和录屏目录，不替换已安装版本，也不接收正式更新。`make smoke` 会使用独立测试包，结束后注销并归档；开发包退出后可运行 `python3 scripts/native.py archive-test` 归档。可以用 `--test-id` 固定测试身份，用 `--app-output` 指定测试 App 的完整路径；归档时使用同样的参数。

构建优先使用本机唯一的 Apple Development 证书，也可通过 `MOOJICUT_SIGNING_IDENTITY` 指定证书；无证书时使用临时签名。正式包使用 `make release` 生成，只保留 ZIP 和校验信息，不自动安装或启动。发布应沿用原签名身份及更新公钥；临时签名构建不能保证屏幕录制授权在更新后继续有效。

根目录是 MoonBit 项目，编辑核心位于 `src/`，默认编译为 native。可以单独运行 `moon check`、`moon test` 和 `moon build`，检查、测试与构建核心。各平台的原生界面共用这一核心。业务逻辑按领域放在 `src/internal/`，根包保留稳定的原生接口；目录与依赖说明见[核心代码说明](../src/README.md)。

### 打包示例插件

准备好 MoonBit 工具链和 Python 后，在仓库根目录运行：

```sh
python3 scripts/package_plugin.py plugins/examples/capture-info --output dist/capture-info.zip
```

脚本构建 WebAssembly 插件并生成包含 `manifest.json` 和 `plugin.wasm` 的 ZIP；首次构建会下载示例依赖。将生成的 ZIP 按上文步骤导入 macOS 应用，即可使用「截图信息」和「查看尺寸」。制作自己的插件可从[示例说明](../plugins/examples/capture-info/README.md)开始；运行方式与能力边界见[用户插件说明](../plugins/user-runtime/README.md)。

## 关于 Mooji Cut

Mooji Cut 使用 MoonBit 编写标注与剪辑状态，搭配各平台原生界面和系统采集能力。截图与录屏在本机处理，让捕捉、编辑和分享成为连贯的几步操作。
