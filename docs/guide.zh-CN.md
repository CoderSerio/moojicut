# Mooji Cut 使用与构建指南

[English overview](../README.en.md) · [返回中文首页](../README.md)

本指南对应已发布的 `0.1.0-alpha.22`，具体交付范围见[该版本发布说明](https://github.com/CoderSerio/moojicut/releases/tag/v0.1.0-alpha.22)。当前仍处于 alpha 阶段：已实现和通过自动检查的功能，不等于已在所有桌面环境与用户设备上完成验收。

## 下载与开始使用

打开[官网下载页](https://coderserio.github.io/moojicut/#download)，按系统下载。官网优先使用验证过的 Cloudflare 镜像，连接失败时切换至同版本的 GitHub 下载。alpha.22 提供下表三种平台的安装包及 SHA-256 校验文件。

| 系统 | 运行要求 | 打开方式 |
| --- | --- | --- |
| Windows | Windows 10/11，Intel / AMD x64 | 解压 ZIP，双击 `MoojiCut.exe`，从任务栏托盘菜单开始截图或录屏 |
| macOS | Apple Silicon，macOS 26.0 或更新版本 | 解压 ZIP，将 Mooji Cut 放入「应用程序」并打开，从菜单栏图标进入 |
| Linux | Ubuntu 22.04/24.04 x86_64 及兼容发行版，glibc ≥ 2.35，安装下方运行依赖 | 解压 tar.gz，在目录中运行 `./launch.sh`，从设置或托盘开始截图、录屏 |

下载的应用无需安装 MoonBit 或 Python。关闭设置会继续在后台待命；完全退出请使用菜单栏或托盘中的「退出 Mooji Cut」。

Windows 包免安装，目前尚未进行代码签名，系统可能显示未知发布者提示。macOS 预览包尚未完成 Apple 公证，首次打开可能需要在「系统设置 → 隐私与安全性」中确认。

Linux 包自带固定版本的媒体库。运行依赖见包内 `README.txt`，Ubuntu 22.04 可运行：

```sh
sudo apt install libgtk-3-0 libayatana-appindicator3-1 libcurl4 \
  libportal1 libportal-gtk3-1 libpulse0 libpipewire-0.3-0
```

部分 GNOME 桌面需要 AppIndicator 扩展才能显示托盘；没有图标也可运行 `./launch.sh` 打开设置，或运行 `./moojicut --capture` 直接截图。Wayland 需要 `xdg-desktop-portal` 和当前桌面对应的后端：截图使用 Screenshot 服务，录屏使用 ScreenCast 服务与 PipeWire；只有截图门户可用，并不代表录屏服务可用。安装包不会自动安装这些依赖或修改桌面配置。

## 截图：标出重点，再发出去

框选后可直接原地标注，在画布中输入和重新编辑文字，并调整位置、大小、颜色与字号。工具栏第二行显示当前工具的属性。点击圆形色块选色。透明度、线宽、字号和马赛克颗粒可直接输入，或用框内上下箭头和滚轮微调。Wayland 通过门户取得图片后进入无边框编辑界面，定位与置顶效果取决于桌面合成器。

三端的框线工具均提供方框、圆框（椭圆）；覆盖工具提供方框、圆框和马赛克，可在工具的二级属性中切换。三端共用形状选择和悬停说明。选中马赛克后可调整颗粒大小（4–48 像素），不显示颜色和透明度。形状偏好按工具记忆；选中已有标注可以切换形状并撤销，复制结果会保留所选形状和马赛克效果。

属性控件使用同一套交互，各工具的样式分别保存：在本次编辑中切换文字、矩形、箭头或填充覆盖，会恢复该工具上次使用的颜色、不透明度及适用的字号或线宽。选中已有标注后修改属性，只影响该标注；取消选择或重新切换工具，就会回到新建标注的默认样式。

浮动工具栏按当前工具与属性控件调整宽度，启停插件或切换工具后会重新排布；空间不足时可横向滚动工具行。工具栏仅有两个分组：左侧是标注、用户工具、文字识别/翻译和撤销/重做；右侧是贴图、取消和完成，中间一条分割线。绘图光标仅用于画布操作，移到工具栏按钮上会恢复普通指针，文字输入框使用文字光标。

macOS 的「选择」工具可以选中已有矩形边框、箭头、文字或遮挡，拖动移动。矩形、文字和遮挡可拖动控制点调整大小；箭头可分别调整两个端点。按 Delete 删除当前标注，移动、缩放和删除都支持撤销。文字双击可继续编辑；这是对标注对象的编辑，不会把截图原始像素识别成独立对象。

**框选 → 标注 → 确认 → 复制图片**

1. 从菜单启动截图，或使用默认快捷键。
2. 选好区域后，添加矩形/椭圆框线、箭头、文字、填充覆盖或马赛克。需要完全盖住原图内容时，使用填充覆盖并将不透明度设为 100%。
3. 不满意可撤销或重做。点击复制后，将保留原图尺寸的图片放入剪贴板。
4. 回到聊天或文档中粘贴。按 `Esc` 或取消会关闭本次编辑，保留原有剪贴板内容。

首次在 macOS 截图时，需要允许「隐私与安全性 → 屏幕与系统音频录制」权限；授权后按系统提示重新打开应用。Wayland 的截图选择与授权由系统门户处理，取消授权不会替换剪贴板。

## 文字识别与翻译（macOS）

选好截图区域后，在工具栏点击「文字」。应用打开统一的「截图文字」窗口并识别原文；需要翻译时，选择语言后点击「翻译」，在「原文 / 译文」之间切换。两者处理的是当前截图内容，包括已有标注。

识别结果和译文都可以修改。可选择源语言与目标语言；自动识别原文语言失败时，手动选择源语言后重试。修改原文或语言后，点击「翻译」重新生成译文。需要重新读取这张截图时，点击「重新识别」；需要中止处理时，点击「取消任务」。右下角的复制按钮始终复制当前显示的内容；只有点击它才会改变剪贴板。

文字识别与翻译均在本机处理。翻译使用 macOS 支持的语言组合；首次使用某些语言时，需要联网并在系统弹窗中允许下载语言资源。下载未完成、所选语言组合不受支持或系统无法识别原文语言时，窗口会提示原因。Windows 与 Linux 目前尚未接入这两项功能。

## 滚动截图（暂时关闭）

滚动截图仍需修复，当前版本默认不显示工具栏入口。待真实页面拼接和交互完成修复、验证后再开放。

## 插件管理：选择工具和导入插件

在 Windows 和 macOS 打开「设置 → 插件管理」，在 Linux 打开「设置 → 截图工具」。在「截图工具」分类中，可分别启用或停用矩形、箭头、文字、遮挡（填充覆盖）和贴图；选中一项后，点击「上移」或「下移」调整顺序。标注和用户工具在左侧功能组中按设置顺序显示；贴图作为结束截图的动作，固定放在右侧操作组。停用的工具会从工具栏中隐藏。启用状态和顺序自动保存，重新打开应用后仍会保留。

停用标注工具不会删除画面中已有的标注。贴图开关与「设置 → 通用」中的「启用贴图」双向同步；关闭贴图会移除现有贴图并释放贴图快捷键，详见下节。

同一个 v2 ZIP 可以导入三端。旧 v1 插件需要按[新契约](../plugins/spec/capture-v2.md)重新打包。Windows 和 Linux 使用默认插件图标。用户扩展目前面向截图工具。

**导入 ZIP → 管理工具 → 在截图工具栏调用**

1. 在工具管理页点击「导入插件…」，选择作者提供的预编译插件 ZIP。应用会检查插件包并运行一次健康检查；导入时无需安装 MoonBit，也不会编译插件源码。
2. 导入成功后，在「截图工具」列表中逐项启用或停用新增工具，选中一项后用「上移」「下移」调整顺序。新工具追加在列表末尾，顺序和开关自动保存。
3. 启动截图并选好区域，从截图工具栏选择插件工具。Numbered Box 示例可以点击查看尺寸，也可以拖框后添加带编号的标注。
4. 文本结果可以手动复制。插件添加的一批标注可以一次撤销。

插件收到截图尺寸、格式、文档版本和适用的框选坐标，返回声明的文本或标注。导入时的健康检查不接收截图信息。重新打开应用会恢复已安装插件与工具偏好。

导入相同插件的新 ZIP 可替换已安装版本，保留相同工具的顺序和开关。通过「卸载插件…」可移除该插件的全部工具并取消正在运行的调用；重新安装相同工具 ID 可恢复原偏好。卸载不会删除已有截图标注，也不保证立即回收旧插件包占用的磁盘空间。

## 贴图：留在原处，随时参考

点击图钉，编辑结果会固定在当前截图的位置和尺寸。拖动可以移动；双击关闭，或单击选中后按 `Esc` 关闭。选中贴图后用 `+` / `-` 缩放，用 `⌘`（macOS）或 `Ctrl`（Windows / Linux）配合 `+` / `-` 调整不透明度。

macOS 再次截图时，可见的贴图会留在画面中，可以把之前固定的图片一起框选进去；主动隐藏的贴图仍保持隐藏。

隐藏/恢复默认使用 macOS 的 `⌘ ⇧ H`，Windows / Linux X11 使用 `Ctrl + Shift + H`。有选中贴图时切换当前贴图；未选中时，若有隐藏项就恢复隐藏项，否则隐藏全部。恢复会保留此前的不透明度。

鼠标穿透默认使用 macOS 的 `⌘ ⇧ P`，Windows / Linux X11 使用 `Ctrl + Shift + P`。穿透期间保留选中目标，鼠标交给下面的应用；贴图不会响应缩放、隐藏、Esc 或双击关闭，再按同一组合解除。应用只有在恢复快捷键可用时才允许进入穿透。也可以从菜单栏或托盘选择“恢复隐藏贴图”或“解除鼠标穿透”。Wayland 暂不启用鼠标穿透。

以上按键均可在贴图快捷键设置中修改。隐藏与穿透的恢复键需要组合键，方便切到其他应用后仍能找回贴图。

在「设置 → 通用」中可关闭贴图功能。关闭会立即移除现有贴图（包括隐藏和穿透中的贴图），释放贴图快捷键，截图编辑仍可继续。重新开启后即可创建新贴图，原来的快捷键配置会保留；已关闭的图片不会重新出现。

## 录屏：剪掉多余，再分享过程

### macOS

**选择画面 → 3 秒倒计时 → 停止录屏 → 时间线编辑 → 保存 MP4**

macOS 可从菜单栏「开始录屏…」、默认快捷键 `⌘ ⇧ 2`，或「设置 → 快捷键 → 截图与录屏」中的按钮开始。直接进入桌面选区：拖拽框选任意区域，悬停高亮窗口后单击选中，单击桌面空白可选择整屏。选区右下方可切换系统声音；点击录制或按回车后显示 3 秒圆环倒计时，下方取消按钮或 `Esc` 可退出。窗口模式跟随所选窗口移动；区域模式固定录制该显示器上的区域。目前不录麦克风。录制期间菜单栏显示录制标记和时长，使用 `⌘ ⇧ X` 或菜单栏的「停止录屏并编辑」结束。

录制画面保留比例，最长边限制为 3840 像素、30 fps。停止后等待文件写入完成，再打开视频编辑器。上方查看成片，下方时间线调整片段；图标工具栏集中显示常用操作，鼠标停留可查看说明。

1. 点击时间线定位播放位置，按空格播放或暂停。前进、后退按钮每次跳转成片时长的 1%，最多 5 秒；左右方向键逐帧定位，按住 `Shift` 配合方向键每次移动十帧；`Home` / `End` 跳到成片起点或终点。时间轴使用 `⌘ +` / `⌘ -` 放大、缩小，`⌘ 0` 适应全部成片（共享组件在其他宿主使用 `Ctrl`）。也可按住修饰键滚轮缩放，普通滚轮横移；缩放不产生剪辑记录。
2. 选中片段后，可在播放位置切分，再调整片段顺序或裁剪片段边界。拖拽只改编辑草稿和预览，裁短后时间轴保留原来的比例和空间，可以把边界重新拉回。删除片段会留下空隙；使用「删除并合拢」或选中空隙后删除，可让后面的内容接上。`Shift + Delete` 用于删除并合拢。
3. 展开音轨可以查看原声音频；有音轨的素材会异步生成片段波形，辅助定位声音。波形会随片段裁剪、移动和实际变速对应到时间线；分析未完成或不可用时仍可编辑、播放和导出。有关联的音视频一起调整；解除关联后，可独立选择和移动音频位置。没有视频的区间显示黑场，没有音频的区间保持静音。
4. 「预览速度」只改变当前观看速度，不影响保存文件。「片段实际速度」会改变所选片段与成片时长。没有关联音频的视频可以慢放；有关联音轨或独立音频的片段暂不支持慢放，界面会禁用对应选项。加速音频使用保音调处理，实际听感因素材和倍率而异。
5. 可按需要静音或裁剪画面范围，编辑支持撤销与重做。当前使用同一段录屏，不支持导入多个素材、复制片段按钮、字幕、转场或缩放聚焦关键帧。
6. 点击「保存视频」才编码生成成片，默认文件名为 `moojicut_yyyyMMdd_HHmmss.mp4`，时间取自原录屏的创建时间。选择新的 MP4 保存位置，不能覆盖原片。导出按当前剪辑计划生成文件，预览倍率不会改变结果；取消导出不会覆盖已有目标文件。

macOS 的原片、旧版草稿和新草稿分别保留在 `~/Library/Application Support/MoojiCut/` 下的 `Drafts`，可从菜单「继续编辑上次录屏…」重新打开。升级后继续编辑不会改写原录屏或旧版草稿。「保存视频」写入用户选择的位置；预览和取消任务不会写入剪贴板。

### Windows

**框选区域 → 3 秒倒计时 → 停止录屏 → 时间线编辑 → 保存 MP4**

1. 从托盘「开始录屏」或默认快捷键 `Ctrl + Shift + 2` 启动，在冻结桌面上自由拖选区域。松开鼠标后进入 3 秒倒计时；选区或倒计时阶段可按 `Esc` 取消，倒计时面板也提供取消按钮。
2. 按所选区域录制，保留画面比例，最高 1920 × 1080、15 fps，包含鼠标指针。区域固定在桌面坐标，不跟随窗口移动。当前不录系统声音或麦克风，也不支持暂停。
3. 使用托盘菜单或 `Ctrl + Shift + X` 停止，等待原片写入完成后进入现有视频编辑器。系统支持排除自身窗口时也会显示录中控制条；停止快捷键和托盘入口仍可使用。
4. 在时间线上切分、移动、修剪、变速或裁画面。编辑即时预览，保存时才导出 MP4。应用保留原片，退出编辑后可继续上次草稿。

原片和编辑草稿保存在 `%LOCALAPPDATA%\MoojiCut\Drafts\`，成片由「保存视频」写入所选位置。Windows N 版需要安装系统媒体功能包才能录屏。录制或收尾失败时会保留原片或未完成文件，并在错误提示中给出路径；保留文件不代表已验证可播放。

### Linux

**选择来源 → 3 秒倒计时 → 停止录屏 → 时间线编辑 → 保存 MP4**

1. 从托盘或「设置 → 通用」点击「开始录屏…」，也可在解压目录运行 `./moojicut --record`。
2. **X11**：在冻结桌面拖选区域后按 `Enter` 确认；尚未拖选时，直接按 `Enter` 可录制整个屏幕。过小的选区会要求重选，不会自动扩大为全屏。按 `Esc` 取消。**Wayland**：在系统 ScreenCast 界面中授权并选择一个显示器或窗口；范围由桌面提供，当前不支持应用自定义的区域框选。
3. 来源准备完成后显示 3 秒倒计时，点击取消按钮或按 `Esc` 可退出。录制开始前隐藏倒计时窗口；当前不保证任意桌面后端都能排除其他自有窗口。
4. 从托盘或设置中停止录屏，也可运行 `./moojicut --stop`。等待原片写入后打开共享时间线，可切分、裁剪、变速并保存 MP4。原片是静音 VP8/WebM，最高 1920 × 1080、15 fps。Wayland 当前录制不包含鼠标指针。

原片自动保存到系统配置的视频目录下的 `Mooji Cut/recording-XXXXXX/source.webm`（通常位于 `~/Videos/`）；未设置视频目录时使用用户数据目录。失败时保留 `source.partial.webm` 并显示路径，不覆盖已有文件；未完成文件不一定可播放。

Linux X11 可在应用内设置全局截图、录屏和停止快捷键。Wayland 的全局快捷键由系统门户授权，取决于桌面后端。也可以使用 `moojicut --capture`、`moojicut --record` 或 `moojicut --stop`。

| 截图 | `⌘ ⇧ 1` | `Ctrl + Shift + 1` |

## 应用内更新

在「设置 → 更新」中检查 GitHub Releases，无需登录 GitHub。开发预览版会接收更新的预览版和正式版；正式版只接收正式更新，不会自动降级。检查失败、网络超时或 GitHub 限流时会显示原因，稍后可重试。

macOS 请将正式应用放在 `/Applications/Mooji Cut.app`，之后从「设置 → 更新 → 检查更新」下载、安装并重新打开，更新会替换原位置的应用。更新信息和安装包均按应用内置公钥校验。如果该版本还没有签名源，设置会提示打开发布页手动下载。默认手动检查，也可以开启自动检查，应用不会静默安装。截图或录屏编辑尚未结束时，会等待你完成当前操作。下载时可以取消；验证失败不会安装该更新。

Windows 与 Linux 可在更新页下载对应平台的安装包，校验大小及 SHA256 后保存到选择的位置；下载可以取消，失败时不会覆盖已有文件。下载完成后点击打开文件位置，退出旧版本，再手动解压并运行新版本。这两个平台目前尚不支持自动替换正在运行的应用。

更新沿用原有的快捷键、偏好设置和录屏草稿存储位置。首次安装仍需下载应用；旧版若没有更新入口或提示更新源不可用，可从[最新版本下载页](https://github.com/CoderSerio/moojicut/releases/latest)手动换装。alpha.22 已验证公开安装包校验值与 macOS 更新签名；真实原位升级、系统授权与用户设置保留仍待用户设备验收，不能把发布检查视为覆盖安装已通过。

发布包沿用原签名身份和应用位置，以维持系统识别的一致性，但不能保证 macOS 永不再次提示授权。升级后若有系统提示，请按提示处理；无需为了更新主动重置屏幕录制权限或保留多份应用副本。

## 从源码构建

准备支持 native 静态库的 MoonBit 工具链和 Python 3.12 或更新版本；Windows / Linux 的 CI 固定使用 MoonBit `0.10.20+65efd5b93`。

- macOS：Xcode Command Line Tools 及支持 macOS 26 的 SDK。
- Windows：MSVC C++ Build Tools 与 Windows SDK，在 x64 Native Tools 开发终端中运行。
- Linux：C 编译器、`pkg-config`、GTK 3、Ayatana AppIndicator、libcurl、GStreamer、libportal GTK 3、GIO Unix 和 X11 开发包；运行录屏还需上文的 GStreamer 插件及对应桌面服务。Ubuntu 开发包包括 `libgtk-3-dev libayatana-appindicator3-dev libcurl4-openssl-dev libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev libportal1 libportal-dev libportal-gtk3-dev libx11-dev`。

在仓库根目录运行：

```sh
python3 scripts/desktop.py dev --release-version 0.1.0-alpha.22
```

Windows 可将 `python3` 换成 `python`；macOS 与 Linux 也可使用 `make dev`。构建后会启动应用并打开设置。

macOS 首次构建会下载并校验固定版本的 Sparkle 更新框架和 Extism 插件运行时。开发构建名为 `Mooji Cut Test …`，使用独立应用身份、偏好、插件和录屏目录，不替换已安装版本，也不接收正式更新。`make smoke` 会使用独立测试包，结束后注销并归档；开发包退出后可运行 `python3 scripts/native.py archive-test` 归档。可以用 `--test-id` 固定测试身份，用 `--app-output` 指定测试 App 的完整路径；归档时使用同样的参数。

构建优先使用本机唯一的 Apple Development 证书，也可通过 `MOOJICUT_SIGNING_IDENTITY` 指定证书；无证书时使用临时签名。正式包使用 `make release` 生成，只保留 ZIP 和校验信息，不自动安装或启动。发布应沿用原签名身份及更新公钥；临时签名构建不能保证屏幕录制授权在更新后继续有效。

根目录是 MoonBit 项目，编辑核心位于 `src/`，默认编译为 native。可以单独运行 `moon check`、`moon test` 和 `moon build`，检查、测试与构建核心。各平台的原生界面共用这一核心。业务逻辑按领域放在 `src/internal/`，根包保留稳定的原生接口；目录与依赖说明见[核心代码说明](../src/README.md)。

### 打包示例插件

准备好 MoonBit 工具链和 Python 后，在仓库根目录运行：

```sh
python3 scripts/package_plugin.py plugins/examples/numbered-box --output dist/numbered-box.zip
```

脚本构建 WebAssembly 插件并生成包含 `manifest.json` 和 `plugin.wasm` 的 ZIP；首次构建会下载示例依赖。将生成的 ZIP 按上文步骤导入应用，即可查看截图尺寸或拖框添加编号标注。[插件作者指南](../plugins/user-runtime/README.md)

## 关于 Mooji Cut

Mooji Cut 使用 MoonBit 编写标注与剪辑状态，搭配各平台原生界面和系统采集能力。截图与录屏在本机处理，让捕捉、编辑和分享成为连贯的几步操作。
