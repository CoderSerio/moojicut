<h1 align="center">Mooncap</h1>

<p align="center"><strong>截下重点，录下过程。</strong></p>
<p align="center">以 MoonBit 为核心的本地截图与录屏工具。</p>

Mooncap 面向日常沟通里的小片段：一张需要圈出重点的截图，一段需要说明操作的录屏。捕捉后编辑，确认后复制，再回到原来的工作。

**当前为 macOS 原生开发预览版。** 已可体验菜单栏和偏好设置；下面的完整截图、录屏流程正在接入。

## 捕捉之后，把重点说清楚

### 截图：标出重点，再发出去

框选画面后，就在原处添加箭头、文字和高亮，遮住不想分享的信息。调整满意后确认，图片进入剪贴板，回到聊天或文档中直接粘贴。

**框选 → 标注 → 确认 → 复制图片**

### 录屏：剪掉多余，再分享过程

录下操作步骤，结束后裁掉首尾、删去等待片段、调整画面范围，或去掉声音。确认后生成视频文件，并把文件放到剪贴板。

**录制 → 裁剪与编辑 → 确认 → 复制视频文件**

## 日常使用，尽量少打扰

- **从菜单栏开始。** 截图与录屏有各自的快捷键；关闭设置后继续在后台待命。
- **编辑完成，再确认。** 捕捉之后留出调整内容的机会，确认的默认动作是复制到剪贴板。
- **围绕本地文件设计。** 素材、可编辑草稿和导出成品保存在本机，方便继续修改与再次分享。

## 本地体验

目前提供源码构建的 macOS 开发预览版。准备好 Xcode Command Line Tools、Node.js 22+ 和 [MoonBit 工具链](core/README.md) 后，在仓库根目录运行：

```sh
npm run dev:native
```

构建后会启动 Mooncap 并打开设置。应用平时驻留菜单栏，关闭设置不会退出；完整构建、测试和本地签名说明见 [开发指南](native/README.md)。

## 用 MoonBit 做编辑核心

MoonBit 负责图片与视频的编辑模型、命令、撤销重做和导出计划，编译为原生静态库，由 macOS 的 AppKit 宿主直接调用。原生应用不打包 Electron 或 WebView，Node.js 仅用于开发构建。后续平台适配继续复用这部分核心逻辑。
